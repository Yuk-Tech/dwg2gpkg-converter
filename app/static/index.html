Ubah Gambar Ukur jadi File Peta

Ubah file gambar ukur (DWG atau DXF) jadi file peta (GPKG) yang bisa langsung dipakai plugin Yuk Generate PBT.

Cara pakai:

  1. Pilih file gambar ukur (DWG atau DXF).
  2. Kalau mau, klik "Lihat isi file" untuk memeriksa lapisan di dalamnya.
  3. Klik "Ubah & unduh" — file peta langsung terunduh.
